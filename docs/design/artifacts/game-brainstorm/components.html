Stable interfaces

  • UI never imports a personality formula
  • Strategies receive only allowed game knowledge
  • Controller cannot mutate scores directly
  • Selectors prevent duplicated derived state

Boundary guardrails

  • No timers inside the reducer
  • No random calls hidden in components
  • No score/rank copies in React state
  • No research simulator in the v1 bundle
